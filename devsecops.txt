1. Installing Git
 Windows: Download from git-scm.com
 Linux:
 sudo apt-get install git
 macOS:
 brew install git
Check installation:
git --version

2. Basic Git Configuration
Git git config --global user.name &quot;Your Name&quot;
git config --global user.email &quot;your.email@example.com&quot;
Check config:
git config --list

3. Git Workflow Basics
1. Working Directory → Your local files
2. Staging Area → Files marked for commit
3. Repository → Stored commits history

4. Creating a Repository
Initialize Git in a folder:
git init
Clone an existing repository:
git clone &lt;repository_url&gt;

5. Tracking Files
Add files:
git add filename

git add . # add all files
Commit changes:
git commit -m &quot;Commit message&quot;
View status:
git status

6. Branching and Merging
 Create a branch:
 git branch feature-branch
 Switch branch:
 git checkout feature-branch
 Create &amp; switch together:
 git checkout -b feature-branch
 Merge branch:
 git checkout main
 git merge feature-branch

8. Remote Repositories
 Add remote repo :
 git remote add origin &lt;url&gt;
 Push changes:
 git push origin main
 Pull updates:
 git pull origin main
 Fetch without merging:
 git fetch origin

9. Undoing Changes
 Unstage file:
 git reset filename
 Discard local changes:
 git checkout -- filename
 Revert commit:
 git revert &lt;commit_id&gt;

10. Collaboration with GitHub
 Forking → Create your own copy of a repo
 Pull Request (PR) → Propose changes to a repo

 Issues → Report bugs or request features
 Project Boards → Manage tasks visually
